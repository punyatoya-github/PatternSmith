# Test images

Put your own test photos in this folder (they are git-ignored so you never commit private photos).

Week 1 checklist from the plan: collect 15 to 20 images covering
portraits, pets, logos, flowers, landscapes and a few low-contrast photos.

`synthetic/` holds small generated images (see `scripts/make_test_images.py`) so tests and the
benchmark work on a fresh clone without any photos.
